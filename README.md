# 紫微斗數 · 定盘与解盘

> 以十二宫为纸，十四主星为墨。先校正出生时辰，再谈命局。

一个单页的紫微斗数排盘工具：可以排十二宫命盘、用十三个时辰逐一比对来「定盘」，再从命宫、三方四正、四化、大限流年几个角度读盘。界面取道家水墨与朱砂的颜色，不做预测，只做传统文化框架下的结构解读。

**在线使用：** <https://nikon1koni.github.io/ziwei-doushu/>

![预览](assets/preview.jpg)

## 功能

- **排盘**：公历 / 农历输入，支持闰月、性别、出生城市与经度。
- **真太阳时**：按经度差 + 均时差校正钟表时间；也可以关掉，按原时间排。
- **十二宫命盘**：命宫、身宫、十四主星、辅星、杂曜、庙旺利陷、四化、大限区间，一屏读完。
- **定盘**：同一出生日期排出早子到晚子十三个时辰，对照命宫主星、身宫落点、太阳太阴旺陷与性格描述，挑一张更像自己的盘。
- **解盘**：顶部先给一段白话总览（基础底色 + 生年四化 + 给你的提醒），下面再用命局总览、十二宫、四化、大限流年四个页签细读；附术语小抄。
- **本地存档**：上次填写的出生信息存在浏览器 localStorage，下次打开不用重填。

## 定盘怎么用

1. 先按记得的出生时间排一张盘，不必精确到分钟。
2. 到「定盘」区，看十三个时辰卡片：重点比对命宫主星、身宫落在哪个宫、太阳太阴的旺陷。
3. 回忆 3–5 件人生大事发生的年份，看哪个时辰的大限、流年宫位更有呼应。多件交叉验证，比只看性格更可靠。
4. 选中后点「以此定盘」，命盘、四柱、解盘会一起更新。

传统上以「多件事都能对上」的时辰可信度较高；单看一条只能作参考。出生在 22:55–23:05 附近时，注意是否跨了子时。

## 本地运行

不需要构建，也不需要联网：

```bash
git clone https://github.com/nikon1koni/ziwei-doushu.git
cd ziwei-doushu
# 直接双击 index.html，或起一个静态服务器
python -m http.server 8000
```

打开 `http://localhost:8000/` 即可。`iztro.min.js` 是本地依赖，和 `index.html` 放在同一目录。

## 技术说明

- 纯 HTML / CSS / JavaScript，单页应用，无打包步骤。
- 排盘规则使用开源库 [iztro](https://github.com/SylarLong/iztro)（v2.6.5，UMD 本地引入）。
- 真太阳时 = 经度时差（每偏离 120°E 一度约 4 分钟）+ 均时差近似式。
- 命盘格子按地支定位：巳午未申 / 辰…酉 / 卯…戌 / 寅丑子亥，中间为命局信息。
- 解读文字与星曜词典为传统文化视角的整理，不构成医疗、投资、婚姻等任何现实决策建议。

## 声明

紫微斗数属于传统命理文化，本工具用于排盘规则、命理结构与界面设计的展示与研究。定盘不是「认命」，只是把模糊的出生时间落到一张更贴近经历的盘上；真正的生活仍由你自己决定。
